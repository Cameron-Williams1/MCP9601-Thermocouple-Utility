Static Fire Logger

Operator manual for recording up to six K-type thermocouple channels, read by Adafruit MCP9601 (MCP96L01) amplifiers, from a Feather RP2040 Adalogger to a laptop over USB.

01 / Operation

Record a run#

  1. Connect the Feather by USB and close Arduino Serial Monitor or any other app using its port.
  2. Start the recorder by running Computer/static_fire_recorder.py (see Set up the recorder). Keep the laptop awake and the USB cable connected throughout the run.
  3. Check the row for each amplifier address, up to six. Each connected probe should show a plausible temperature and OK. An unused input can show No thermocouple.
  4. Click Start recording. Confirm the row count increases. When finished, click Stop and save.

Each recording creates a new StaticFire_…csv in the current user’s Downloads folder. A preview alone does not create a file. No SD card is required.

Review

Graph a saved run#

In the Thermocouple Date Logger window, select CSV Graph → Open CSV…. Select a StaticFire USB or FLIGHT SD recording. The graph shows elapsed seconds and temperatures in °C; unplugged or faulted probes leave gaps. You can review a file without connecting a Feather.

02 / Data

Understand the readings#

Each row is one event from one address. Channels update independently. Use the board timestamps to align them; adjacent rows need not be simultaneous. Repeated temperatures can be separate conversions. A fault event has no temperature.

CSV fieldMeaning
host_utcUTC time when the laptop processed the event.
board_time_usMicroseconds since board startup when the firmware reported the result. Use differences for elapsed time.
sequenceBoard event counter across all channels.
addressAmplifier address, one of up to six.
statusOK, OPEN (no probe/open circuit), SHORT or I2C_ERROR.
temperature_CProbe temperature in Celsius for valid readings; otherwise blank.
missing_usb_events_beforeGap in the board event sequence since the last received row. A board reset restarts its counter; start a new run after a reset.

The firmware uses the fastest 12-bit conversion setting, trading temperature resolution for speed. Bench measurements produced approximately 36–40 valid readings per second per connected probe. The window updates once per second; the CSV retains individual events, including faults. The displayed event rate includes fault reports.

03 / Firmware

Install or restore the board#

The Feather is already configured. To restore the USB recorder on the same board model, hold BOOTSEL, tap RESET, release BOOTSEL, then copy StaticFireUSB.uf2 to RPI-RP2. The board restarts automatically.

The active USB firmware is an Arduino sketch. The desktop recorder is Python. To rebuild the firmware, use Arduino-Pico 6.2.0 and select “Adafruit Feather RP2040 Adalogger.” The STEMMA chain uses SDA GPIO2 and SCL GPIO3.

Other board modes#

Board/Optional SD Logger contains the earlier standalone SD firmware. Board/Optional CircuitPython Monitor contains the earlier board Python program and its libraries. For that slower monitor, install its CircuitPython UF2 in BOOTSEL mode, then copy only code.py and lib to CIRCUITPY. Run desktop_monitor.py on the laptop with the packages in Computer/requirements.txt. These modes replace the USB firmware and use a different serial format; restore StaticFireUSB.uf2 to use the fast recorder.

Set up the recorder#

The recorder is a Python program, so it runs on any computer with Python. Create a virtual environment, install Computer/requirements.txt with pip and run Computer/static_fire_recorder.py. Ensure the user’s Downloads folder exists.

04 / Field reference

Troubleshooting#

What you seeWhat to check
Feather not connectedUse a USB data cable, confirm the correct firmware, close other serial tools, then click Reconnect.
No thermocouple / SHORTCheck the two probe leads at that address. An open input is expected on unused channels.
No recent dataCheck USB power and the STEMMA chain. If USB disconnected during recording, reconnect and start a new file.
File errorCheck free disk space and that your system allows the program to write to Downloads.
